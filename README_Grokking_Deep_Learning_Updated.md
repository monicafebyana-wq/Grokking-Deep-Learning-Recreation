# Ringkasan Setiap Chapter

## Chapter 1 --- Introducing Deep Learning: Why You Should Learn It

Chapter pertama memperkenalkan konsep dasar deep learning dan alasan
mengapa bidang ini penting dipelajari.

Pembahasan: - Artificial Intelligence - Machine Learning - Deep
Learning - Perkembangan dan aplikasi deep learning - Persiapan Python
dan NumPy

Chapter ini menjadi dasar sebelum memahami cara kerja neural network.

------------------------------------------------------------------------

## Chapter 2 --- Fundamental Concepts: How Do Machines Learn?

Chapter kedua membahas bagaimana mesin dapat belajar dari data.

Pembahasan: - Hubungan AI, Machine Learning, dan Deep Learning -
Supervised Learning - Unsupervised Learning - Parametric dan
Nonparametric Learning - Konsep Predict, Compare, dan Learn

Chapter ini menjelaskan konsep dasar proses pembelajaran mesin.

------------------------------------------------------------------------

## Chapter 3 --- Introduction to Neural Prediction: Forward Propagation

Chapter ketiga mulai membangun neural network sederhana.

Pembahasan: - Input, weight, dan output - Single input dan single
output - Multiple inputs - Multiple outputs - Operasi matrix menggunakan
NumPy - Forward propagation

Chapter ini menjelaskan bagaimana neural network menghasilkan prediksi.

------------------------------------------------------------------------

## Chapter 4 --- Introduction to Neural Learning: Gradient Descent

Chapter keempat membahas bagaimana neural network melakukan
pembelajaran.

Pembahasan: - Error prediction - Membandingkan prediction dengan
target - Hot and cold learning - Gradient descent - Learning rate -
Update weight

Chapter ini menjelaskan bagaimana model memperbaiki kesalahan.

------------------------------------------------------------------------

## Chapter 5 --- Learning Multiple Weights at a Time

Chapter kelima mengembangkan gradient descent untuk menangani banyak
parameter.

Pembahasan: - Multiple inputs - Multiple weights - Weight update -
Multiple outputs - Representasi matrix - Hubungan weight dengan pola
data

Chapter ini menjelaskan bagaimana neural network belajar dengan banyak
weight secara bersamaan.

------------------------------------------------------------------------

## Chapter 6 --- Building Your First Deep Neural Network

Chapter keenam membangun deep neural network pertama.

Pembahasan: - Streetlight problem - Matrix relationship - Deep neural
network - Learning dataset - Full gradient descent - Batch gradient
descent - Stochastic gradient descent - Backpropagation introduction -
Linear dan nonlinear network

Chapter ini menggabungkan konsep sebelumnya menjadi jaringan deep
learning.

------------------------------------------------------------------------

## Chapter 7 --- How to Picture Neural Networks: In Your Head and on Paper

Chapter ketujuh membahas cara memahami struktur neural network melalui
visualisasi.

Pembahasan: - Struktur neural network - Input layer - Hidden layer -
Output layer - Hubungan antar neuron - Representasi weight - Membaca
arsitektur jaringan

Chapter ini membantu memahami jaringan yang semakin kompleks.

------------------------------------------------------------------------

## Chapter 8 --- Learning from Multiple Layers: Introduction to Backpropagation

Chapter kedelapan memperdalam konsep backpropagation.

Pembahasan: - Forward propagation pada banyak layer - Error
propagation - Backward propagation - Weight update - Training neural
network multi-layer

Chapter ini menjelaskan bagaimana error digunakan untuk memperbaiki
seluruh jaringan.

------------------------------------------------------------------------

## Chapter 9 --- Modeling Probabilities and Nonlinearities: Activation Functions

Chapter kesembilan membahas activation function yang membuat neural
network mampu mempelajari pola nonlinear.

Pembahasan: - Fungsi aktivasi - ReLU - Sigmoid - Tanh - Softmax -
Derivative activation function - Activation pada neural network

Chapter ini menjelaskan peran nonlinearitas dalam deep learning.

------------------------------------------------------------------------

## Chapter 10 --- Introducing Convolutional Neural Networks (CNN)

Chapter kesepuluh memperkenalkan Convolutional Neural Network untuk
pengolahan data gambar.

Pembahasan: - Permasalahan pengolahan gambar dengan neural network
biasa - Konsep convolution - Filter dan kernel - Feature map - Feature
detection - Reuse weight - Pooling - Struktur CNN sederhana

Chapter ini menjelaskan dasar computer vision menggunakan deep learning.

# Cara Menjalankan Repository

Clone repository:

``` bash
git clone https://github.com/username/Grokking-Deep-Learning-Recreation.git
```

Masuk folder:

``` bash
cd Grokking-Deep-Learning-Recreation
```

Install dependencies:

``` bash
pip install -r requirements.txt
```

Jalankan Jupyter Notebook:

``` bash
jupyter notebook
```
